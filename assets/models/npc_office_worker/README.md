# Coffee Shift — NPC 01 «Офисный работник» (PS2+)

Первый функциональный прототип 3D-покупателя в стилистике PS2+ для России начала 2010-х годов. Авторский процедурный ассет, без сторонних моделей и текстур.

## Файлы
- `npc_office_worker_ps2plus.glb` — игровая 3D-модель со скелетом и анимациями, после восстановления из архива.
- `npc_office_worker_ps2plus.glb.xz` — **точная lossless-копия** GLB, 13,9 КБ вместо 207,8 КБ.
- `unpack_office_worker.py` — восстановление GLB из XZ со сверкой SHA256; требует только Python 3.
- `npc_office_worker.tscn` — сцена Godot 4.3+ с коллизией и экземпляром GLB.
- `npc_office_worker.gd` — контроллер анимаций `idle`, `walk`, `order`, `receive`.

Если GLB отсутствует, запустите из корня репозитория:
```bash
python3 assets/models/npc_office_worker/unpack_office_worker.py
```
Проверенная сумма SHA256 GLB: `7827bcafd23c3d3affc14785fdbb080d6482c200ae14e60d23ec1cd7e405def0`.

## Характеристики
- Рост: 1,85 м
- Геометрия: 1 176 треугольников
- Риг: 17 суставов
- 21 простой материал, без внешних текстур
- Клип `idle` (3,6 с), `walk` (1 с), `order` (2,3 с), `receive` (2,3 с)

## Подключение
В Godot 4.3+ открыть `npc_office_worker.tscn`, затем вызывать `play_activity("walk")`, `play_activity("order")`, `play_activity("receive")`. В DEV-04 исходный пакет проверен в запущенной игре на Godot 4.3 / Linux GL Compatibility: импорт, четыре анимации, капсула коллизии и масштаб, 16 проверок без ошибок (`tests/office_worker_asset.gd`). Реальные кадры находятся в `docs/dev04/screenshots/office_worker_asset/`.

Замена текущих покупателей этим ассетом ожидает визуальной приёмки. Пакет не добавляет навигацию, очередь, диалоги или кассовую логику и не меняет используемую игровую модель NPC.
