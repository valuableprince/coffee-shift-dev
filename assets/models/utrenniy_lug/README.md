# Пакет молока — DEV-03, переработанная версия

Простой бело-синий литровый пакет с двускатным верхом, бумажными сгибами и запаянным швом. Без текста, дат, марки и иллюстраций. Габариты около 78 × 76 × 245 мм, основание Y=0.

Сцены `milk_carton.tscn` и `milk_carton_open.tscn` сохраняют `opened`/`set_opened()`. Геометрия собственная, внешние текстуры не используются. Старые SVG сохранены как исходники прежнего дизайна.

В торговой сцене пакет стоит на передней части нижней полки `ShiftFridge`, а не на столешнице. Сначала открывается дверца, затем молоко берётся отдельным E с полки. Сток учитывается системой ингредиентов, видимый пакет представляет доступный запас. Проверено в Godot 4.3/GL Compatibility. Предпросмотр модели — `scenes/asset_preview_milk.tscn`.
