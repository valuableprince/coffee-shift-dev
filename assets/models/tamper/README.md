# Темпер Coffee Shift — самостоятельный low-poly 3D-ассет

Модель темпéра (тампера) для уплотнения молотого кофе в корзине рожка. Предназначена для Godot 4.3+ и единого стиля **PS2+ / Cozy Realism**. Это реальный объёмный меш в метрах, не изображение.

## Комплект

- `coffee_shift_tamper.glb` — основной игровой ассет (glTF 2.0 Binary); 131028 байт, без внешних текстур.
- `tamper.tscn` — сцена Godot с точками хвата, контакта с кофе и установки.
- `create_blend.py` — импортирует GLB и сохраняет редактируемый файл `.blend`.
- `README.md` — спецификация, схема координат и проверка.

## Габариты

| Параметр | Значение |
| --- | --- |
| Диаметр плоской подошвы | **53,5 мм** |
| Наружный диаметр верхней части рукоятки | около 41 мм |
| Общая высота | **114,5 мм** |
| Координаты | Y вверх, центр подошвы (0,0,0), единицы — метры |
| Контактная поверхность | горизонтальная плоскость Y = 0 |
| Сцена Godot | масштаб 1:1 (без рескейла) |

Диаметр 53,5 мм выбран намеренно: подготовленный в PR #65 портафильтр имеет отверстие около **55 мм**. Для него нельзя без проверки использовать распространённую подошву диаметром 58 мм. Перед выпуском проверить фактический диаметр корзины финальной кофемашины.

## Геометрия / материалы

- Плоская стальная подошва с аккуратной фаской.
- Металлическое плечо, полированная втулка и рельефные кольца.
- Тёмная эргономичная бакелитовая рукоятка с сужением для хвата и расширением сверху.
- Минимальные акценты без надписей и внешних UI-элементов.
- 13 именованных меш-частей, 3374 вершин, 6728 треугольников, 6 встроенных PBR-материалов.
- Диапазон координат Y: 0.0000..0.1145 м.

## Интеграция в игровой процесс

Ассет не трогает DEV-03, рецепты, состояние рожка и логику приготовления. Для будущего взаимодействия сценой предусмотрены:

- `HandGrip` — центр хвата игроком на рукоятке;
- `PressContact` — центр рабочей плоскости подошвы;
- `StandPivot` — опорный маркер постановки.

Коллизии, логика трамбовки, прокручивание и игровая анимация добавляются отдельно при реализации соответствующего действия. При показе подсказок следовать уже утверждённой системе: маленькая постоянная точка в центре экрана, название предмета — **только при наведении**. Не ставить постоянные таблички на объект.

## Blender

```bash
blender --background --python assets/models/tamper/create_blend.py
```

Либо File → Import → glTF 2.0 → `coffee_shift_tamper.glb`, затем File → Save As → `.blend`.

## Проверка

1. Открыть `tamper.tscn` в Godot 4.3+; проверить целостность импортируемого меша и материалов.
2. Проверить вертикальную ось и постановку на плоскую подошву.
3. При примерке убедиться, что подошва входит в **внутренний** диаметр корзины портафильтра из PR #65; не увеличивать до 58 мм без смены корзины.
4. Проверить читаемость металлической подошвы и тёмной рукоятки при тёплом рабочем освещении.
5. Провести отдельный игровой тест захвата / трамбовки после интеграции механики.
