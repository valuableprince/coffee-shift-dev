# Рожок (портафильтр) — Coffee Shift

Самостоятельный низкополигональный 3D-ассет портафильтра для **Coffee Shift** (Godot 4.3+, PS2+ / Cozy Realism).

## Состав

- `coffee_shift_portafilter.glb` — настоящий glTF 2.0 Binary, без внешних текстур.
- `portafilter.tscn` — Godot-сцена c моделью и точками крепления.
- `create_blend.py` — создаёт редактируемый .blend импортом готового GLB в Blender.

## Ориентация и размеры

Единицы: **метры**. Центр корзины — X=0, Z=0; ось Y вверх.
Корзина открыта сверху, рукоятка направлена вдоль **+Z** (к игроку).
Наружный диаметр корзины ~67 мм, внутренний ~55 мм; длина от корзины до конца рукоятки ~237 мм.
Нижняя точка двух носиков Y≈-0.067 м; верх корзины Y≈0.013 м.
Поворачивать/масштабировать только через родительский Node3D; исходный GLB оставлять в масштабе 1:1.

## Конструкция

- Металлическая полая корзина с кольцевым ободом, перфорацией дна и двумя боковыми зацепами.
- Пара патрубков выдачи кофе внизу.
- Стальной переходник и утолщённая тёмная бакелитовая рукоятка, с тонкой металлической окантовкой.
- 22 именованных частей, 2952 вершин, 4559 треугольников, 6 встроенных PBR-материалов.
- Без подписей и несъёмных игровых UI-элементов.

## Интеграция

Эта версия добавляет **только ассет**, не изменяя сцену исходной кофемашины, рецепты или логику DEV-03.
В ветке `feat/espresso-machine-dev03-polish` исходный GLB кофемашины уже содержит встроенные `Portafilter_Left_*`; при последующей интеграции нужно скрывать **их** при снятии рожка и показывать данную отдельную модель в руках/на столе, а не одновременно обе модели.

Для привязки используйте маркеры `GroupLockOrigin`, `HandGrip`, `SpoutExitLeft` и `SpoutExitRight` в `portafilter.tscn`.
Существующий игровой стейт `filter` и стадии приготовления остаются источником истины. Коллизию и функции захвата задаёт игровая сцена, а не визуальный GLB.

## Blender

```bash
blender --background --python assets/models/portafilter/create_blend.py
```

Или импортируйте GLB через File → Import → glTF 2.0; затем сохраните как .blend.

## Проверка

1. Откройте `portafilter.tscn` в Godot 4.3+; проверьте корзину и ручку со стороны +Z.
2. Убедитесь, что обе металлические зацепы видны, внутренняя корзина полая и носики направлены вниз.
3. При примерке к кофемашине учитывайте масштаб экземпляра кофемашины 0.80 и коррекцию высоты группы 0.14 м из адаптера PR #64.
4. Проверить видимость без артефактов при штатном освещении; игровой подбор и снятие этим PR не реализуются.
