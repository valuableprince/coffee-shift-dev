# Питчер для молока — Coffee Shift

Оригинальный игровой 3D-ассет питчера из нержавеющей стали, в стиле **PS2+ / Cozy Realism**. Подготовлен под Godot 4.3+ и Blender; это полноценная открытая полая модель, а не изображение.

## Файлы

- `coffee_shift_milk_pitcher.glb` — самостоятельный glTF 2.0 Binary; PBR-материалы встроены, внешние текстуры не нужны.
- `milk_pitcher.tscn` — Godot-сцена и пять маркеров для будущего взаимодействия.
- `create_blend.py` — импорт GLB в Blender и сохранение редактируемого `.blend`.
- `README.md` — размеры, точки привязки, контроль качества.

## Геометрия

- Полый конический (слегка расширяющийся кверху) корпус с **открытой горловиной**, внутренними стенками и плоским дном.
- Выраженный **литой носик** для контроля струи при латте-арте; геометрия носика интегрирована в верхнюю кромку, а не выполнена отдельным треугольником.
- Обкатанная полированная кромка горловины.
- Прочная С-образная металлическая ручка с двумя точками приварки.
- Тонкое кольцо основания и упрощённые PBR-материалы нержавеющей стали без логотипов и декоративных табличек.

| Характеристика | Значение |
| --- | --- |
| Тип | Металлический молочный питчер, номинал ~600 мл |
| Высота до носика | ~125 мм |
| Диаметр корпуса у горловины | ~94 мм (без вылета носика) |
| Диаметр основания | ~77–81 мм |
| Направление носика | **+Z** |
| Направление ручки | **−Z** |
| Ось высоты | **+Y** |
| Положение опорной поверхности | Y≈0.001 м |
| Масштаб | **1 единица = 1 м**, импорт 1:1 |
| Геометрия | 9 mesh-частей, 2958 вершин, 5280 треугольников |
| Материалы | 6 встроенных PBR |

**Объём 600 мл указан как номинал дизайна, а не как проверенная градуировка.** Для игрового учёта молока использовать состояние механики, не объём меша.

## Godot

Добавьте `milk_pitcher.tscn` в нужную игровую сцену. Подсказки показывайте только при наведении постоянной центральной точки прицела; ничего не подписывайте на 3D-модели.

- `HandGrip` — место захвата игроком;
- `PourSpout` — кончик носика, откуда позже будет исходить струя;
- `MilkSurfaceOrigin` — нижняя точка для будущего уровня наполнения;
- `SteamWandTarget` — примерная область размещения паровой трубки;
- `BaseContact` — привязка модели к поверхности столешницы.

В этом PR добавляется **только визуальный ассет**: без новой системы вспенивания, молока, сохранения, коллизий и анимации наклона. Последующие механики должны использовать уже существующее состояние DEV-03; нельзя создать дублирующую систему.

## Blender

```bash
blender --background --python assets/models/milk_pitcher/create_blend.py
```

Либо File → Import → glTF 2.0 (.glb) → `coffee_shift_milk_pitcher.glb`, затем сохраните `.blend`.

## Проверка после импорта

1. Убедиться, что питчер стоит ровно вертикально, без дополнительного масштаба.
2. Осмотреть горловину сверху: внутренняя полость не должна быть закрыта.
3. Проверить ровный край стенки, узнаваемый носик и незамкнутую С-образную ручку с отступом от корпуса.
4. Проверить, что носик направлен по +Z, ручка — по −Z и все маркеры доступны в дереве.
5. Посмотреть при дневном освещении игры и при вечернем освещении: стальной корпус не должен выглядеть чёрным/пересвеченным.
6. Игровые тесты захвата, вспенивания и переливания проводить **после** интеграции соответствующей механики.
