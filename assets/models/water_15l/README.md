# Бутылка воды — DEV-03, переработанная версия

Прозрачная ребристая ПЭТ-бутылка с синей крышкой, без этикетки, текста и рисунков. Пропорции около 90 × 338 мм, условный объём 1,5 л. Основание на Y=0; в игре стоит на левой столешнице.

`water_bottle.tscn` и `water_bottle.gd` используют замкнутый низкополигональный корпус, сдержанную прозрачность и видимый уровень воды. `opened`/`set_opened()` оставлены для варианта без крышки. Предпросмотр — `scenes/asset_preview_water.tscn`.

Геометрия собственная, внешние текстуры не используются. Старый SVG сохранён только как исходник прежней версии. Проверено в Godot 4.3, в том числе GL Compatibility.
