# Coffee Shift — мойка со смесителем (PS2+)

Авторский комплект игровых 3D-ассетов для компактного кофейного трейлера России начала 2010-х. Godot 4.3+, Windows, Blender 3.6+ / 4.x. Единый стиль PS2+ / Cozy Realism: нержавеющая сталь, мягкая угловатость, умеренные отражения. Никаких сторонних моделей, фотографий или внешних текстур.

## Файлы

- `stainless_sink_basin.glb` — настоящая полая мойка с бортиком, скруглёнными внутренними стенками, открытым сливным отверстием и внешней нижней оболочкой.
- `gooseneck_mixer_body.glb` — отдельный смеситель с изогнутым изливом, аэратором и креплением к полке мойки.
- `mixer_lever.glb` — отдельный подвижный рычаг, который можно поворачивать вокруг локального pivot.
- `drain_strainer.glb` — отдельная решётка слива с восьмью перемычками и настоящими открытыми промежутками между ними.
- `sink_with_mixer.tscn` — сцена Godot, собирающая все четыре GLB, с приближёнными коллизиями и Marker3D.
- `sink_mixer.gd` и `sink_mixer_target.gd` — управление положением рычага и контекстной подсказкой.
- `preview.tscn`, `preview.gd` — автономный предпросмотр без запуска основной игры.
- `create_blend.py` — создание редактируемого `.blend` из четырёх GLB.
- `test_asset.py` — проверка структуры, индексов, размеров и сцены без внешних зависимостей.

## Размеры и ориентация

Координаты в **метрах**, ось **Y вверх**, **+Z к игроку**, −Z к стене (задняя полка под смеситель). Начало координат в центре внешнего контура мойки на уровне столешницы.

- Бортик мойки: **440 × 480 мм**.
- Глубина чаши: приблизительно **170–180 мм** ниже верхней плоскости.
- Отверстие чаши: ~**357 × 341 мм**, смещено к передней части.
- Максимальная высота излива относительно столешницы ~**300 мм**.
- Слив: приблизительно X=0, Z=0.045 м.
- Рычаг: pivot при X=0.103, Y=0.035, Z=−0.186 м.
- Струя воды (будущая игровая система): `WaterOutlet` при (0, 0.203, −0.031).

Габариты рассчитаны на существующий стол у левой рабочей линии. Предыдущая процедурная «мойка» имела около 420 × 480 мм. Новый бортик шире на 20 мм; при размещении проверить свободный зазор.

## Важно: вырез в столешнице

**Не устанавливать новую чашу поверх сплошной столешницы.** У мойки есть реально углублённая чаша, поэтому в столешнице нужно вырезать проём под неё. Ориентировочно **370 × 365 мм**, с проверкой точного контура и толщины столешницы. В самой модели проём под слив настоящий, но подключение к водопроводу пока не смоделировано.

Для предварительного просмотра приложена сцена с раздельными плитами столешницы вокруг выреза — она показывает реальную углублённую геометрию.

## Управление

```gdscript
$SinkWithMixer.set_faucet_on(true)
$SinkWithMixer.set_faucet_on(false)
$SinkWithMixer.toggle_faucet()
$SinkWithMixer.set_faucet_on(true, false) # restore without animation
```

Плавный поворот рычага на ~28° за 0.30 секунды; сигнал `faucet_state_changed(is_on)`.

Стандартный метаданный target на коллизии рычага: `action="sink_mixer_lever"`, методы `get_prompt()` / `interact()`. Маленькая точка прицела остаётся частью основного HUD. Постоянных подписей над оборудованием нет.

Самостоятельный ввод через E **выключен по умолчанию**, чтобы не конфликтовать с действующим контроллером. Для интеграции следует либо маршрутизировать E на `CoffeeShiftSinkMixerTarget.interact()`, либо явно включить `enable_fps_input_adapter` — но не оба способа одновременно.

Пока не реализованы: водоснабжение, физическая струя воды, мойка посуды, сохранение водных ресурсов, сантехническое подключение. Поворот рычага — визуальная механика ассета, не полноценная система воды.

## Проверки и Blender

В Godot открыть `res://assets/models/sink_mixer/preview.tscn` и запустить F6. Enter/Space изменяет положение рычага.

```sh
python assets/models/sink_mixer/test_asset.py
blender --background --python assets/models/sink_mixer/create_blend.py
```

Blender-скрипт создаст `coffee_shift_sink_mixer.blend`. Все геометрические элементы оригинальны, модели уже находятся в GLB. Ни одна существующая игровая сцена не заменена в этом PR.
