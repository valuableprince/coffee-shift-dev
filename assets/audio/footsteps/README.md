# Footsteps — Kenney Impact Sounds 1.0

Public development copy: nine original, unmodified OGG recordings: `footstep_wood_000–004.ogg` and `footstep_concrete_000–003.ogg`.

`footstep_concrete_004.ogg` remains in the private source repository. The public loader skips missing optional variants; this exception is tracked in `docs/PUBLIC_MIGRATION.md`.

Wood is used inside the trailer, concrete outside. Available non-looping variants are cycled with small pitch differences; steps are triggered by actual horizontal distance travelled. Volume follows the existing Effects/Master settings.
