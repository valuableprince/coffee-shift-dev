# Rubik Medium — dialogue typeface

Source: [Google Fonts / Rubik](https://github.com/google/fonts/tree/main/ofl/rubik), upright `Rubik[wght].ttf`, retrieved 2026-11-06.

`Rubik-Medium.ttf` is a static weight-500 instance produced with FontTools (`instantiateVariableFont`, `updateFontNames=True`). No glyph designs were edited. This avoids variable-font weight differences between engine versions. It includes Cyrillic, Ё/ё and the rouble sign. Godot's default fallback supplies control-arrow symbols.
